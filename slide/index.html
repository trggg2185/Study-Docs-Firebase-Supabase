05 · Luồng nghiệp vụ

lên cloud như thế nào?

Đăng nhập

Google Sign-In → Firebase Auth trả về uid.

Tải file

App upload file vào Storage theo thư mục của user.

Lưu metadata

Firestore lưu thông tin tài liệu và fileUrl.

Đọc / xoá

06 · Bắt đầu triển khai

Setup Firebase
theo bốn chặng.

Tạo project

Tạo project trong Firebase Console; mời thành viên và cấp đúng quyền.

Cài công cụ

Cài Firebase CLI và FlutterFire CLI; đăng nhập tài khoản được cấp quyền.

Cấu hình app

Chạy flutterfire configure, chọn project và nền tảng đích.

Khởi tạo SDK

Thêm packages, gọi Firebase.initializeApp() trước khi chạy app.

Packages chính

firebase_core · firebase_auth · cloud_firestore · firebase_storage · google_sign_in

Thiết lập dịch vụ

Bật Google Sign-In; tạo Firestore và Storage; chọn region gần người dùng, ví dụ asia-southeast1.

07 · Bảo mật

Danh tính phải gắn với
quyền sở hữu.

Cloud Firestore

Chỉ cho phép thao tác khi đã đăng nhập và uid khớp với ownerId.

allow read, write: if request.auth != null && request.auth.uid == resource.data.ownerId;allow create: if request.auth != null && request.auth.uid == request.resource.data.ownerId;

Cloud Storage

Lưu file theo đường dẫn riêng của user; đối chiếu uid với userId.

match /documents/{userId}/{allPaths=**} { allow read, write: if request.auth != null && request.auth.uid == userId;}
Quan trọng: kiểm thử Rules bằng Firebase Emulator Suite; không dùng Test mode để phát hành. Rules mẫu cần được rà soát cho đúng schema và thao tác thực tế.

09 · FAQ

Những điều cần biết
trước khi mở rộng.

Firestore có full-text search?

Không. Nếu cần tìm kiếm toàn văn, cân nhắc Algolia hoặc Elasticsearch.

Mất mạng thì sao?

Firestore hỗ trợ offline trên Android/iOS và đồng bộ lại khi có mạng; Web cần cấu hình thêm.

Vượt gói miễn phí?

Theo dõi quota và chi phí; Blaze tính phí theo mức sử dụng.

Xoá tài liệu cần làm gì?

Xoá metadata Firestore và file Storage; cân nhắc xử lý lỗi để tránh dữ liệu mồ côi.

10 · Demo / kiểm tra

Từ “đã cấu hình”
đến “chạy an toàn”.

Checklist khởi chạy

Đã gọi Firebase.initializeApp().
Đã bật Google Sign-In và thêm SHA-1 cho Android.
Firestore và Storage dùng đúng project / region.
Rules giới hạn truy cập theo user; đã kiểm thử.
Config cục bộ nằm ngoài Git.

Mẹo xử lý lỗi nhanh

  • no-app → kiểm tra khởi tạo Firebase.
  • sign_in_failed → kiểm tra SHA-1 / cấu hình Android.
  • PERMISSION_DENIED → kiểm tra trạng thái đăng nhập và Rules.
  • command not found → kiểm tra PATH của FlutterFire CLI.
  • Unsupported platform → chạy lại flutterfire configure.
Kiểm thử luồng đăng nhập → upload → xem danh sách → xoá, trên cả trạng thái có mạng và mất mạng.
